# Design direction

- Palette: Void `#000000`, Ink `#070912`, Signal `#315CFF`, Decision `#7657FF`, Ice `#DDE5FF`, Quiet `#949BB0`.
- Type: Instrument Sans for precise product language; Newsreader italic for rare moments about judgment and reality.
- Layout: a 12-column field with left-biased editorial statements interrupted by full-width operating interfaces.
- Motion: one hero orchestration, then user-triggered state transitions and one-time explanatory reveals.

```text
desktop:  [progress rail] [editorial claim.............]
                         [interactive system full field]
                         [evidence    | decision output]

mobile:   [progress]
          [claim]
          [interactive system]
          [evidence]
```

## Uniqueness review

The first direction leaned toward a dark SaaS dashboard. That would have made the content feel like a set of portfolio cards, which the brief explicitly rejects. The revised direction uses a luminous continuous signal-line as the only recurring motif. Sections switch modes: editorial, diagnostic console, decision instrument and system map. This range keeps the artifact varied without becoming decorative. Violet is reserved for changed state; blue marks live evidence. Rounded containers are used only where the user can operate something.
